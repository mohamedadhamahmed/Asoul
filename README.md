# منظومة ساس العائلية | Saudi Family SaaS Simulation (Phase 1)

محاكاة برمجية تفاعلية شاملة وخفيفة بنظام **Multi-tenant SaaS** موجهة لإدارة وتوثيق العوائل السعودية، مبنية بتقنيات الويب النقية (HTML5, Tailwind CSS, FontAwesome, JavaScript) ومجهزة لتسليم المرحلة الأولى (Phase 1) وعرضها أمام العميل.

---

## 🚀 كيفية تشغيل المشروع
يمكنك تشغيل المشروع فوراً بأي من الطرق التالية دون الحاجة لتثبيت أي برامج إضافية:

1. **الطريقة المباشرة:** النقر المزدوج على ملف `index.html` لفتحه في أي متصفح (Edge / Chrome / Safari).
2. **عبر خادم محلي (اختياري):**
   ```bash
   cd saudi-family-saas
   python -m http.server 8000
   ```
   ثم فتح: `http://localhost:8000`

## 👥 تغطية السيناريوهات الثلاثة المطلوبة

### 1️⃣ سيناريو أونر المنصة (SaaS Super Admin)
- **إدارة بيئات العوائل:** كل عائلة تمثل بيئة مستقلة وشجرة منفصلة.
- **نظام باقات الساس المتصاعد:**
  - **باقة العائلة البسيطة (1 - 100 فرد):** 200 ر.س / سنوياً.
  - **باقة العائلة الممتدة (101 - 1,000 فرد):** 400 ر.س / سنوياً.
  - **باقة القبيلة والكيانات الكبرى (1,001 - 10,000 فرد):** 600 ر.س / سنوياً.
- **إنشاء بيئة جديدة:** زر مخصص لإنشاء شجرة جديدة وتعيين الأدمن المسؤول وتوليد بطاقة تسليم الحساب فورياً.
- **تسليم الحساب للأدمن:** بطاقة جاهزة بنص منسق لبيانات الدخول ورابط البيئة لنسخها وإرسالها للأدمن عبر WhatsApp أو الإيميل.

### 2️⃣ سيناريو أدمن ومسؤول العائلة (Family Admin)
- **الداشبورد الحيوي:**
  - شريط متابعة استهلاك الباقة الحالية مع مؤشر الترقية التلقائية للباقة التالية عند زيادة الأفراد.
  - عداد أفراد الشجرة وتوزيع الأجيال.
  - عداد الأخبار (معتمدة vs بانتظار الاعتماد).
  - عداد الوثائق والأرشيف (معتمدة vs بانتظار الاعتماد).
- **المشجرة التفاعلية والأعضاء:**
  - رسم بياني بصري لشجرة العائلة مقسم حسب الأجيال (المؤسسون، الأبناء، الأحفاد، البراعم).
  - إمكانية إضافة ابن لأي شخص بالنقر المباشر عليه.
  - زر **"دعوة عبر واتساب ويب"**: توليد رسالة ترحيبية برابط دعوة مخصص مع زر فتح واتساب ويب مباشرة (`https://web.whatsapp.com/send?...`).
- **مركز الاعتماد والموافقات:**
  - تدقيق واعتماد الأخبار والمناسبات المرفوعة من أفراد العائلة (اعتماد / رفض).
  - تدقيق واعتماد الوثائق التاريخية والمخطوطات (اعتماد وأرشفة / رفض).
- **سجل العمليات الحيوية (Activity Log):**
  - جدول زمني مباشر يرصد كافة حركات الأفراد: تسجيل الدخول، إضافة أبناء، ورفع المنشورات.

### 3️⃣ سيناريو فرد العائلة (Family Member Portal)
- **تسجيل الدخول والتحقق برقم الجوال:**
  - التحقق من تطابق رقم الجوال مع الرقم المسجل مسبقاً من الأدمن في الشجرة لمنع الدخول غير المصرح به.
  - **محاكاة رمز OTP التجريبي (Phase 1):** يظهر صندوق أنيق يحاكي رسالة الـ SMS ويوضح كود التحقق التجريبي (مثلاً `5821`) مع زر "إدخال تلقائي وتأكيد" لتسهيل العرض أمام العميل دون تكلفة رسائل SMS.
- **بوابة العضو الشخصية:**
  - تعديل الملف الشخصي (الاسم، المدينة، المهنة، النبذة).
  - **إضافة فرد جديد تحتي (ابن/ابنة):** ينعكس فوراً في شجرة العائلة ويزيد عداد المشتركين ويحدّث باقة الساس آلياً!
  - **نشر خبر / مناسبة عائلية:** زواج، مولود جديد، تخرج، لقاء عائلي (يذهب لمركز اعتماد الأدمن).
  - **رفع وثيقة تاريخية أو صورة قديمة:** صكوك، صور، مخطوطات نسب (تذهب لمركز اعتماد الأدمن).
  - **متابعة طلباتي:** تتبع حالة المنشورات (⏳ بانتظار الموافقة / ✅ تم الاعتماد والنشر).

## 💡 نصائح لعرض المحاكاة أمام العميل (Demo Script)
1. ابدأ من شريط التبديل العلوي في دور **أونر المنصة**، واستعرض جدول العوائل وكيف تُحسب الباقة آلياً حسب عدد الأفراد.
2. انتقل إلى دور **أدمن العائلة**، وافتح المشجرة التفاعلية، ثم انقر على "دعوة عبر واتساب ويب" وأظهر للعميل الرسالة المجهزة.
3. بدّل إلى دور **بوابة الفرد**، واختر حساب (فيصل بن فهد: `0509876543`)، واشرح له فكرة محاكاة OTP.
4. بعد الدخول كفرد، اضغط على **"إضافة فرد جديد تحتي"** وأضف مولوداً جديداً، ثم عُد إلى لوحة الأدمن لتُري العميل كيف زاد العداد واقترب من ترقية الباقة!
5. انشر خبراً من حساب الفرد، ثم عد كأدمن لتُظهر له إشعار الاعتماد الفوري في مركز الموافقات.
